# Shield Tech Dashboard

Painel simples de visualização de vulnerabilidades (Versão Autônoma).

## Como rodar o projeto

Você só precisa da pasta `frontend`. O projeto não possui backend.

1. Navegue até a pasta frontend:
   `cd frontend`
2. Instale as dependências:
   `npm install`
3. Inicie o servidor:
   `npm run dev`

Acesse `http://localhost:5173` no seu navegador.
